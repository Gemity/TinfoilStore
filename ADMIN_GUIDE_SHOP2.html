# Huong Dan Quan Tri Tinfoil Store

Trang quan tri: **http://160.187.229.43/docs**

Tai lieu nay danh cho nguoi van hanh shop hang ngay. Moi thao tac quan tri deu lam tren Swagger `/docs`, khong can chay lenh bash tren may local.

## Thong Tin Shop

```text
Shop:      Tinfoil Store
Server:    160.187.229.43
Docs:      http://160.187.229.43/docs
Shop URL:  http://160.187.229.43/shop/
Protocol:  http
Host:      160.187.229.43
Port:      80
Path:      /shop/
```

Tai khoan admin mac dinh sau deploy:

```text
Username: admin
Password: admin123
```

## 1. Dang Nhap Trang Quan Tri

1. Mo trinh duyet va vao `http://160.187.229.43/docs`
2. Nhan nut **Authorize** o goc tren ben phai
3. Tim muc **HTTPBasic (HTTP, Basic)**
4. Nhap:

```text
Username: admin
Password: admin123
```

5. Nhan **Authorize**
6. Nhan **Close**

Sau do co the dung cac endpoint admin ben duoi.

## 2. Tao User Moi

Moi nguoi dung Tinfoil can mot tai khoan rieng.

1. Tim endpoint **POST /admin/users**
2. Nhan **Try it out**
3. Nhap mau:

```json
{
  "username": "user01",
  "email": "user01@example.com",
  "password": "matkhau123",
  "role": "user"
}
```

4. Nhan **Execute**
5. Neu thay **Code 201** la thanh cong
6. Ghi lai `id` cua user de cap subscription

Luu y:

- `username` khong duoc trung
- `email` phai dung dinh dang va khong trung
- `password` toi thieu 6 ky tu
- `role` de `"user"` cho khach hang

## 3. Xem Danh Sach User

1. Tim endpoint **GET /admin/users**
2. Nhan **Try it out**
3. Nhan **Execute**

Thong tin can quan tam:

- `id`
- `username`
- `is_active`
- `created_at`

## 4. Cap Subscription

Sau khi tao user, can cap subscription de user tai game duoc.

1. Tim endpoint **POST /admin/subscriptions/{user_id}/grant**
2. Nhan **Try it out**
3. Dan `id` cua user vao o `user_id`
4. Nhap thoi han can cap

Cap 30 ngay:

```json
{
  "days": 30,
  "hours": 0,
  "minutes": 0
}
```

Cap 1 nam:

```json
{
  "days": 365,
  "hours": 0,
  "minutes": 0
}
```

Cap 5 phut de test:

```json
{
  "days": 0,
  "hours": 0,
  "minutes": 5
}
```

5. Nhan **Execute**
6. Neu thay `effective_status = active` la xong

## 5. Gia Han Subscription

1. Tim endpoint **POST /admin/subscriptions/{user_id}/extend**
2. Nhan **Try it out**
3. Dan `id` cua user vao o `user_id`
4. Nhap mau:

```json
{
  "days": 30,
  "hours": 0,
  "minutes": 0,
  "notes": "Gia han 30 ngay"
}
```

5. Nhan **Execute**
6. Xem `ends_at` de biet han moi

## 6. Thu Hoi Subscription

1. Tim endpoint **POST /admin/subscriptions/{user_id}/revoke**
2. Nhan **Try it out**
3. Dan `id` cua user vao o `user_id`
4. Nhap ly do:

```json
{
  "reason": "Vi pham quy dinh"
}
```

5. Nhan **Execute**
6. Neu thay `effective_status = revoked` la da thu hoi

## 7. Xem Danh Sach Game

1. Tim endpoint **GET /admin/content**
2. Nhan **Try it out**
3. Nhan **Execute**

Ket qua tra ve la danh sach game hien co trong database shop.

## 8. Cap Nhat Game Moi Tu Wasabi

Khi da upload game len bucket Wasabi cua shop, dung endpoint sync de quet lai noi dung.

1. Tim endpoint **POST /admin/sync**
2. Nhan **Try it out**
3. Neu muon scan toan bo bucket thi de mac dinh
4. Neu muon scan mot thu muc rieng, nhap `prefix`
5. Neu muon xoa game da bi xoa khoi Wasabi, dat `cleanup = true`
6. Nhan **Execute**

Vi du:

```text
POST /admin/sync
POST /admin/sync?prefix=games/
POST /admin/sync?cleanup=true
```

Sau khi sync xong, he thong se:

- quet bucket Wasabi hien tai
- them game moi vao database
- xoa game stale neu bat `cleanup`
- warm local icon/banner cache

Response mau:

```json
{
  "message": "Sync completed and local icon cache warmed.",
  "sync": {
    "added": [],
    "removed": [],
    "total": 2,
    "scanned": 2
  },
  "asset_cache": {
    "titles": 2,
    "iconUrl": 2,
    "bannerUrl": 2
  }
}
```

## 9. Them Game Thu Cong

Chi dung khi that su can tao content bang tay.

1. Tim endpoint **POST /admin/content**
2. Nhan **Try it out**
3. Nhap mau:

```json
{
  "title": "Ten Game [0100XXXXXXXXXXXX][v0].nsp",
  "storage_key": "Ten Game [0100XXXXXXXXXXXX][v0].nsp",
  "size_bytes": 1000000000,
  "is_protected": true
}
```

Giai thich:

- `title`: ten game hien thi
- `storage_key`: duong dan file tren Wasabi
- `size_bytes`: dung luong file
- `is_protected`: de `true` neu can subscription

## 10. Gui Cau Hinh Shop Cho User

Sau khi tao user va cap subscription, gui cho user:

```text
Protocol:  http
Host:      160.187.229.43
Port:      80
Path:      /shop/
Username:  (username da tao)
Password:  (password da tao)
Title:     Tinfoil Store
```

Luu y:

- `Title` chi la ten hien thi
- khong nhap URL vao `Title`
- khong nhap `admin:password@host` vao `Title`
- neu user vao shop thay thong bao chua co subscription, hay kiem tra lai subscription cua user do


## 12. Ma Loi Thuong Gap

| Code | Nghia | Cach xu ly |
|------|-------|------------|
| 200 | Thanh cong | OK |
| 201 | Tao thanh cong | OK |
| 401 | Chua dang nhap | Authorize lai |
| 403 | Khong co quyen hoac chua co subscription | Kiem tra admin role/subscription |
| 404 | Khong tim thay | Kiem tra `user_id`, `content_id` hoac endpoint |
| 409 | Bi trung | Doi username hoac email |
| 422 | Sai dinh dang du lieu | Kiem tra lai JSON |

## 13. Ghi Nho Quan Trong

- Shop dang chay tren `http://160.187.229.43`
- Trang admin la `http://160.187.229.43/docs`
- Tinfoil path la `/shop/`
- Khong can chay lenh tren server de van hanh hang ngay
- Moi thao tac user/subscription/content/sync co the lam trong Swagger
- Icon/banner game duoc cache local tren VPS
- Neu Tinfoil khong thay cover art, kiem tra che do hien thi co dang o grid/icon view hay khong
